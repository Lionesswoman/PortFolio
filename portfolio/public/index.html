    Ma méthode de travail

    Phase 1

    Analyse & conception

    Je recueille les besoins, je modélise le système (UML, Merise) et je planifie les étapes avec un diagramme de Gantt avant d'écrire la moindre ligne de code.

    Phase 2

    Développement

    Je construis brique par brique : base de données, API, interfaces web ou mobile. Chaque étape est versionnée avec Git et présentée pour validation.

    Phase 3

    Déploiement & suivi

    Je conteneurise, je déploie et je documente l'application, puis j'accompagne sa prise en main et ses évolutions.
